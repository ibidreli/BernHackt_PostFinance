# Design System


**Brand reference:** [PostFinance Brand Identity](https://brandfetch.com/postfinance.ch)

## Colors

The design system uses a small, focused color palette:

| Color      | Hex       | Usage                                 |
| ---------- | --------- | ------------------------------------- |
| Yellow     | `#FFCC00` | Primary brand color, highlights, CTAs |
| Green      | `#A5C400` | Secondary accents and positive states |
| Dark Teal  | `#005B61` | Text, navigation, strong contrast     |
| Light Gray | `#F2F2F2` | Backgrounds and subtle surfaces       |
| White      | `#FFFFFF` | Main backgrounds and contrast         |

### Primary Colors

**PostFinance Yellow — `#FFCC00`**
Use for primary actions, key highlights, and brand-forward elements.

**PostFinance Green — `#A5C400`**
Use as a secondary accent or to support positive and active states.

### Supporting Colors

**Dark Teal — `#005B61`**
Use for headings, body text, navigation, and other high-contrast elements.

**Light Gray — `#F2F2F2`**
Use for page backgrounds, cards, dividers, and secondary surfaces.

**White — `#FFFFFF`**
Use as the primary surface color and to provide visual contrast.

## Design Principles

* **Simple** — Keep interfaces clear and easy to understand.
* **Consistent** — Reuse established colors, components, and patterns.
* **Accessible** — Prioritize readable typography and sufficient color contrast.
* **Recognizable** — Use the PostFinance-inspired palette consistently.
* **Functional** — Visual choices should support usability rather than distract from it.

## Usage

When building new interfaces, start with the core color palette and existing components. Avoid introducing new colors or visual patterns unless they serve a clear functional purpose.

The goal is a consistent experience across all screens and products.
